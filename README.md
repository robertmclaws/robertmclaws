# Robert McLaws

I spent my career making it easy as fuck to build applications on .NET.

Now I'm making it easy as fuck to build for Super Intelligence on .NET, too.

I'm a 5× Microsoft MVP (youngest Developer MVP in 2003, at 21), a [.NET Foundation](https://dotnetfoundation.org) member, and CEO of [CloudNimble](https://github.com/CloudNimble).
