# Robert McLaws

25 years of making .NET better through feedback, components, and frameworks.

I'm co-founder and CEO of [CloudNimble](https://github.com/CloudNimble), makers of [EasyAF](https://easyaf.nimbleapps.cloud).
I spent my career making it easy as f\*ck to build applications on .NET.
Now I'm making it easy as f\*ck to build for Super Intelligence on .NET, too.

I'm a 5× Microsoft MVP, awarded for ASP.NET, Windows, and Visual Studio, and a member of the [.NET Foundation](https://dotnetfoundation.org).
